# The Tutorial and This Wiki

Two generated documents live in `documentation/`; both keep themselves honest by reading the code.

## `SPOT_Tutorial.tex` → `SPOT_Tutorial.pdf`

The long-form tutorial (LaTeX). Its appendices (the function reference and the console's commands and non-MATLAB parts) are regenerated by `update_tutorial_reference.py`:

```
python3 documentation/update_tutorial_reference.py     # rewrites the part between the BEGIN/END markers
cd documentation && latexmk -pdf SPOT_Tutorial.tex && latexmk -c
```

<!-- source: documentation/update_tutorial_reference.py -->

**How the script works.** Lines 14–25 list the packages and their section titles; `PURPOSE` (28–42) overrides the one-line purpose where a function's help line is written for a block; `BLOCKS` (44–54) gives the calling form of the System objects and the worker. `tex` (56–61) escapes LaTeX specials; `h1` (63–68) takes the `%NAME ...` help line; `call` (70–87) builds the call signature from the `function` line, marking optional inputs from the function's own `nargin` checks. Lines 89–112 produce one `xltabular` per package (call, purpose); 114–135 the console's commands; 137–165 the non-MATLAB files; 167–177 splice it into the `.tex` between the markers.

The tutorial's PDF is copied into every new project by [[New_SPOT_Project|Tool-New-SPOT-Project]] (when it exists: the folder is git-ignored).

## `wiki/` → the GitHub wiki

These pages. They are written by hand, but three kinds of markers are filled in by `wiki/build_wiki.py` so the pages never show stale code:

| Marker | Filled with |
|---|---|
| `<!-- source: path -->` (one or more at the top) | names the file(s) the page documents |
| `<!-- xref -->` … `<!-- /xref -->` | **Used by** (every file naming this `spot.*` function) and **Uses** (every `spot.*` function it names), with links |
| `<!-- listing -->` … `<!-- /listing -->` | the file's full text, numbered, in a collapsed block: the line numbers the walkthrough refers to |

Each marker must be on a line of its own (that is how the script tells a marker from the same text quoted in a page or in a listing).

`_Sidebar.md` is generated from the table of contents in the script (and every function in each `+spot` package is listed automatically).

```
python3 documentation/wiki/build_wiki.py            # refresh the sidebar, listings and cross-references
python3 documentation/wiki/build_wiki.py --strict   # fail if a +spot function has no page
```

<!-- source: documentation/wiki/build_wiki.py -->

**Publishing.** A GitHub wiki is its own git repository (`<repo>.wiki.git`). Clone it, copy the contents of `documentation/wiki/` into it (pages at the top level, `images/` beside them) and push. Links are `[[Title|Page-Name]]`; images are `images/name.png`; maths is `$…$` / `$$…$$`; diagrams are ```` ```mermaid ```` blocks. The pages are also readable as plain Markdown in the repository.

**Screenshots.** The console pictures in `images/gui-*.png` were taken with a headless browser from a running console with the default settings (a stand-in lab console at 127.0.0.2 for the "Connected" Experiment tab); retake them when the page changes.

 126  CALL_RE = re.compile(r"\bspot\.(\w+)\.(\w+)\b")
 127  SCAN_DIRS = ["+spot", "documentation/demo_execution_order.m", "SPOT.m", "SPOT_User_Parameters.m", "../New_SPOT_Project.m",
 128               "resources/arm_calibration/calibrate_arm.py"]

 132  def scan_files():
 133      files = []
 134      for d in SCAN_DIRS:
 135          p = os.path.join(PROJECT, d)
 136          if os.path.isfile(p):
 137              files.append(p)
 138              continue
 139          for root, dirs, names in os.walk(p):
 140              dirs[:] = [x for x in dirs if x not in ("vendor", "models", "__pycache__", "libowl-src-410")]
 141              for n in names:
 142                  if n.endswith(SCAN_EXT):
 143                      files.append(os.path.join(root, n))

 147  def references(files):
 148      """{(pkg, name): set of files naming spot.pkg.name}, and {file: set of (pkg, name) it names}."""
 149      used_by, uses = {}, {}
 150      for f in files:
 151          try:
 152              text = open(f, encoding="utf-8", errors="replace").read()
 153          except OSError:
 154              continue
 155          found = set(CALL_RE.findall(text))
 156          uses[f] = found
 157          for key in found:
 158              used_by.setdefault(key, set()).add(f)
 159      return used_by, uses

 162  def rel(path):
 163      return os.path.relpath(path, PROJECT).replace(os.sep, "/")

 166  def own_key(source):
 167      m = re.match(r"\+spot/\+(\w+)/(\w+)\.m$", source)
 168      return (m.group(1), m.group(2)) if m else None

 171  def link_for(key):
 172      pkg, name = key
 173      if os.path.isfile(os.path.join(PROJECT, "+spot", "+" + pkg, name + ".m")):
 174          return "[[spot.%s.%s|%s]]" % (pkg, name, page_for(pkg, name))
 175      return "`spot.%s.%s`" % (pkg, name)

 178  def xref_text(sources, used_by, uses):
 179      lines = []
 180      for source in sources:
 181          key = own_key(source)
 182          if key is None:
 183              continue
 184          callers = sorted(rel(f) for f in used_by.get(key, ()) if rel(f) != source)
 185          callees = sorted(k for k in uses.get(os.path.join(PROJECT, source.replace("/", os.sep)), ()) if k != key)
 186          if len(sources) > 1:
 187              lines.append("**%s**" % source)
 188          lines.append("- **Used by:** " + (", ".join("`%s`" % c for c in callers) if callers else "nothing in the code (called by you, from the command window, or by the diagram)"))
 189          lines.append("- **Uses:** " + (", ".join(link_for(k) for k in callees) if callees else "no other spot function"))
 190          lines.append("")
 191      return "\n".join(lines).rstrip() + "\n"

 194  def listing_text(sources):
 195      out = []
 196      for source in sources:
 197          path = os.path.join(PROJECT, source.replace("/", os.sep))
 198          try:
 199              text = open(path, encoding="utf-8", errors="replace").read().rstrip("\n")
 200          except OSError:
 201              out.append("*(%s is missing)*" % source)
 202              continue
 203          lang = {".m": "matlab", ".py": "python", ".js": "javascript", ".c": "c", ".cpp": "cpp", ".cc": "cpp", ".h": "c",
 204                  ".sh": "bash", ".ino": "cpp", ".html": "html", ".css": "css"}.get(os.path.splitext(source)[1], "")
 205          numbered = "\n".join("%4d  %s" % (i + 1, l) for i, l in enumerate(text.split("\n")))
 206          out.append("<details>\n<summary><b>%s</b> (%d lines; click to show)</summary>\n\n```%s\n%s\n```\n\n</details>"
 207                     % (source, text.count("\n") + 1, lang, numbered))
 208      return "\n\n".join(out) + "\n"

 211  def refresh_page(path, used_by, uses):
 212      text = open(path, encoding="utf-8").read()
 213      sources = re.findall(r"^<!-- source: ([^>]+?) -->$", text, flags=re.M)
 214      if not sources:
 215          return False
 216      sources = [s.strip() for s in sources]
 217      new = text
 218      if re.search(r"^<!-- xref -->$", new, flags=re.M):
 219          new = re.sub(r"^<!-- xref -->$.*?^<!-- /xref -->$", lambda m: "<!-- xref -->\n" + xref_text(sources, used_by, uses) + "<!-- /xref -->", new, flags=re.S | re.M)
 220      if re.search(r"^<!-- listing -->$", new, flags=re.M):
 221          new = re.sub(r"^<!-- listing -->$.*?^<!-- /listing -->$", lambda m: "<!-- listing -->\n" + listing_text(sources) + "<!-- /listing -->", new, flags=re.S | re.M)
 222      if new != text:
 223          open(path, "w", encoding="utf-8").write(new)
 224          return True
 225      return False
