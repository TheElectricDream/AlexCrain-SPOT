        Keyboard Shortcuts

        When the editor is not focused:

        A accept as is   S skip   F flag   E edit (focus the editor)   Enter next pending

        ← → previous / next chunk   D diff view   V preview your version   C context   ? this help

        In the editor:

        Ctrl+Enter save your rewrite   Esc leave the editor   Ctrl+F find   Ctrl+Z undo

        A chunk is a comment and the code under it (or a piece of a guide). Accept it if it is right as it is; rewrite it in your own words if you want to own it. Flags are for what you want to come back to. The check line under the editor says whether a rewrite changed only the comments or the code too.
