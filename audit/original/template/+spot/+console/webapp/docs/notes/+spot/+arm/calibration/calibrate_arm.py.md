This script measures the arm's joint friction, back-EMF and inertia on the real servos, in PWM (voltage) control as SPOT drives them, using only PWM and the encoders. The lab console's Calibration tab sends it to the Chaser and runs it there through the Chaser's agent (`spot_agent.sh`: `arm-cal-receive`, `arm-cal-start`, ...), with `--yes`, and reads its `PROGRESS` lines. It can also be run by hand on any computer with the arm's U2D2 adapter. It writes `arm_calibration.json` (version 2, `"control": "pwm"`), which the lab console keeps and projects take with Update from Lab (`Constants.LAB_ARM_*`; `spot.arm.loadCalibration` reads the file itself for bench work), and the raw data as CSV and JSON files in a timestamped folder under `runs/`.

The [Arm Calibration](page:tab-calibration#arm) guide covers the procedure, and [The Arm](page:math-arm) the motor and friction model it fits. Each function's docstring describes it.
