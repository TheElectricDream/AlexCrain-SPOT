## SmoothAngularDifference

The attitude error, measured minus desired, wrapped to [−π, π): the shortest way round, so a platform at +170° asked for −170° turns 20°, not 340°. It is a verbatim copy of the diagram's *Calculate Error* block, so it keeps the block's code exactly (no help text); `spot.control.verifyConsoleController` checks they match.
